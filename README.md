# Sito Val srl – Valorizzazione Ambientale Ligure

Sito statico (HTML + CSS + JS, nessuna dipendenza) per Val srl, impianto di recupero inerti a Cisano sul Neva (SV).

- `index.html` – pagina unica: servizi, come funziona, calcolatore m³→t, codici CER, normative, azienda, FAQ, preventivo, contatti
- `style.css`, `script.js`
- `assets/img` – foto e logo · `assets/docs` – scansioni delle autorizzazioni
